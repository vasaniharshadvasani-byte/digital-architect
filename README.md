# 🏛️ Digital Architect - Portfolio Website

A modern, responsive React portfolio website showcasing digital architectural design and frontend web engineering.

🚀 **Live Demo:** [https://vasaniharshadvasani-byte.github.io/digital-architect/](https://vasaniharshadvasani-byte.github.io/digital-architect/)

---

## 🌟 Features

- **Default Home Route**: Directly loads the portfolio home page on launch.
- **Client-Side Routing**: Smooth page transitions using `React Router` (`HashRouter` for zero-404 GitHub Pages hosting).
- **Responsive Navigation**: Adaptive desktop navbar and mobile slide-out drawer with backdrop blur.
- **Interactive Portfolio Showcase**: Highlights featured work, services, career resume, and contact channels.
- **Performance Optimized**: Production-ready minified build deployed through `gh-pages`.

---

## 🛠️ Tech Stack

- **React 19**
- **React Router DOM 7**
- **FontAwesome Icons**
- **Vanilla CSS** (Custom responsive design system)
- **GitHub Pages** for automated cloud hosting

---

## 🚀 Local Development Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/vasaniharshadvasani-byte/digital-architect.git
   cd digital-architect
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local development server:**
   ```bash
   npm start
   ```
   Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

---

## 📦 Deployment

To deploy updates to GitHub Pages:
```bash
npm run deploy
```
This automatically compiles the optimized production build and publishes it to the `gh-pages` branch.
